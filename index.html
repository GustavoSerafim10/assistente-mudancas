    Catálogo de Mudança Padrão 2025

    Mudança padrão: alteração pré-autorizada de baixo risco e impacto, rotineira e com procedimento estabelecido. O que não está aqui é Normal (ou Emergencial).

    Padrão Procedimento

    1. Tipo da Mudança = Padrão.
    2. Observadores: os da aba Config (+ grupo da torre).
    3. Atribuído: você + parceiro + CGGT > Apoio Governanca.
    4. Marcar os observadores no chat de mudanças pedindo a EXEC direto para a torre.

    Normal Procedimento

    1. Tipo da Mudança = Normal.
    2. Atribuído: você + parceiro + CGGT > Apoio Governanca.
    3. Responder → Fluxo de mudança.
    4. Abrir o PLAN (planejamento) escolhendo as torres envolvidas.

    Emergencial Procedimento

    1. Tipo da Mudança = Emergencial.
    2. Observadores: os ticket managers.
    3. Atribuído: você + CGGT > Apoio Governanca.
    4. Avisar no grupo de mudanças e falar com o ticket manager: “Segue link da mudança emergencial para abrir EXEC e fazer contato com o analista + link”.

    Requisição Ambiente não produtivo

    1. Pedidos para Homologação / Desenvolvimento / Capacitação não são mudança.
    2. Devolver para a Central de Serviços tratar como requisição.
    3. Exceção: excluir recursos de ambientes descomissionados (dev/hmg) é Padrão.

    Script de banco: DDL × DML

    • DML (dados) — INSERT, UPDATE, DELETE, SELECT → Padrão
    • DDL (estrutura) — CREATE, ALTER, DROP, TRUNCATE → Normal
    • Deploy com script de banco → Normal.

    Fechar mudança

    1. Na RDM: conferir se está concluída → status Fechado → print com a solução e o status.
    2. Na GMUD: registrar “RDM encerrada” + print.
    3. Desativar o pop-up do fluxo de mudança pausado.
    4. Remover do campo “Atribuído” o prestador da central.

    Configurações

    Cada colega ajusta com o próprio nome. Fica salvo só neste navegador.
